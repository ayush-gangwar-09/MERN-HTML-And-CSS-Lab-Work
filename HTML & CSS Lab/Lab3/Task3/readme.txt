Task 3.3: Create text-format.html

Aim: Create two paragraphs, use strong and em on one word each, and add a line break inside a paragraph.

Software / Tools Required: HTML editor and web browser.

Theory: The strong element indicates strong importance, em adds emphasis, and br inserts a line break.

Algorithm / Procedure:
1. Create text-format.html.
2. Add two paragraphs.
3. Use strong and em around selected words.
4. Insert br where a new line is required.

Program / Queries / Commands:

text-format.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Text Formatting</title>
</head>
<body>
  <p>Learning <strong>HTML</strong> is useful for web development.</p>
  <p>This is an <em>important</em> note.<br>The next sentence starts on a new line.</p>
</body>
</html>

Input: Two sample paragraphs with emphasized words.

Output: The strong word appears bold, the em word italic, and br starts a new line.
 
Result: The task was performed and the expected output can be verified after running the supplied code/commands.
