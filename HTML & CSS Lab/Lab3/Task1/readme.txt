Task 3.1: Create first.html

Aim: Create first.html with document structure, the title My First Page and an h1 heading Hello, I am Ayush.

Software / Tools Required: HTML editor and web browser.

Theory: HTML provides the structure of a web page. The title element names the browser tab and h1 represents the main heading.

Algorithm / Procedure:
1. Create first.html.
2. Add the HTML document structure.
3. Set the title to My First Page.
4. Add the h1 heading and open the file in a browser.

Program / Queries / Commands:

first.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, I am Ayush Kumar.</h1>
</body>
</html>

Input: Heading text: Hello, I am Ayush Kumar.

Output: Browser tab says My First Page and page displays one large heading.

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
