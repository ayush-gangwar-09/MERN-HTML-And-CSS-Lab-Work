Task 3.2: Create headings.html

Aim: Create h1, h2 and h3 headings followed by a paragraph.

Software / Tools Required: HTML editor and web browser.

Theory: HTML provides six heading levels, from h1 (highest importance) to h6. Paragraphs are marked with the p element.

Algorithm / Procedure:
1. Create headings.html.
2. Add h1, h2 and h3 in order.
3. Add a paragraph below the headings.
4. Open the page in a browser.

Program / Queries / Commands:

headings.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>HTML Headings</title>
</head>
<body>
  <h1>Main Heading</h1>
  <h2>Section Heading</h2>
  <h3>Subsection Heading</h3>
  <p>This is a paragraph describing the page.</p>
</body>
</html>

Input: Any suitable heading and paragraph text.

Output: Three progressively smaller headings and a paragraph are visible

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
