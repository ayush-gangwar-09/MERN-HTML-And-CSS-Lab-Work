# Lab 3: Your First HTML Page

## 📌 Aim
To create basic HTML webpages using document structure, headings, paragraphs, and text-formatting elements.

## 🎯 Objectives
- Understand the basic structure of an HTML document.
- Learn the use of headings and paragraphs.
- Apply text formatting using HTML tags.
- Open and test HTML files in a web browser.

## 📝 Tasks Performed
1. Created `first.html` with the document structure, page title, and an h1 heading.
2. Created `headings.html` using h1, h2, h3, and paragraph elements.
3. Created `text-format.html` with two paragraphs.
4. Used the `<strong>` tag to emphasize important text.
5. Used the `<em>` tag to emphasize text in italics.
6. Added a line break using the `<br>` element.
7. Opened the HTML pages in a browser to verify the output.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood the structure of an HTML document.
- Learned how to create headings and paragraphs.
- Practiced basic text formatting.
- Learned how to run HTML files in a browser.

## ✅ Conclusion
Successfully created basic HTML webpages and practiced headings, paragraphs, emphasis, and line breaks.
