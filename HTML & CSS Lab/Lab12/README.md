# Lab 12: Box Model, Cards and Scrolling

## 📌 Aim
To understand the CSS Box Model, create styled cards, and implement scrolling using the overflow property.

## 🎯 Objectives
- Understand content, padding, border, and margin.
- Compare content-box and border-box.
- Create cards using CSS properties.
- Implement scrolling within a fixed-height container.

## 📝 Tasks Performed
1. Created `box-model.html` with two boxes.
2. Set both boxes to 200px width, 20px padding, and 5px border.
3. Applied `box-sizing: content-box` to the first box.
4. Applied `box-sizing: border-box` to the second box.
5. Created `card.html` with a card element.
6. Applied background color, a 2px border, 12px border radius, and 16px padding.
7. Added a heading and paragraph inside the card.
8. Created `scroll.html` with a fixed-height box of 120px.
9. Added five paragraphs and applied `overflow: auto`.
10. Verified the output in a browser.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood how the CSS Box Model affects element dimensions.
- Learned the difference between content-box and border-box.
- Practiced card styling and spacing.
- Learned how to create scrollable containers.

## ✅ Conclusion
Successfully implemented the CSS Box Model, styled cards, and created a scrollable content box.
