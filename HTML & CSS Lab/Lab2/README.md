# Lab 2: Pushing and Cloning a Repository

## 📌 Aim
To understand remote repositories, pushing commits, and cloning repositories using Git.

## 🎯 Objectives
- Understand the concept of remote repositories.
- Create a bare Git repository.
- Connect a local repository to a remote repository.
- Push commits to a remote repository.
- Clone a repository into another folder.

## 📝 Tasks Performed
1. Created a bare repository named `html-remote`.
2. Added the remote repository using `git remote add origin`.
3. Verified the remote configuration using `git remote -v`.
4. Pushed local commits using `git push origin main` or the appropriate branch name.
5. Created a copy of the repository using `git clone`.
6. Opened the cloned repository and checked the commit history.
7. Verified that the commits were available in the cloned repository.

## 🛠️ Technologies Used
- Git
- GitHub (for remote repository hosting, where applicable)
- Command Line / Terminal

## 📚 Learning Outcomes
- Learned how to configure a remote repository.
- Understood the purpose of Git push and Git clone.
- Learned how to transfer commits between repositories.
- Understood basic repository collaboration workflows.

## ✅ Conclusion
Successfully practiced remote repository configuration, pushing commits, cloning repositories, and verifying commit history.
