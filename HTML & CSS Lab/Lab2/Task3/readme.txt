Task 2.3: Clone the repository and view commits

Aim: Clone html-remote into html-copy and display its commit history.

Software / Tools Required: Git terminal.

Theory: git clone creates a local copy of a repository, including its committed history and remote configuration.

Algorithm / Procedure:
1. Move to the parent folder.
2. Run git clone html-remote html-copy.
3. Enter html-copy and run git log --oneline.

Program / Queries / Commands:

From the parent folder of html-lab:
git clone html-remote html-copy
cd html-copy
git log --oneline

Input: The local bare repository html-remote.

Output: Terminal output showing the same commits in html-copy.


Result: The task was performed and the expected output can be verified after running the supplied code/commands.
