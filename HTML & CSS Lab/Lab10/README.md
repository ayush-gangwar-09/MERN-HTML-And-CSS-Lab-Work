# Lab 10: CSS Fundamentals

## 📌 Aim
To understand different methods of applying CSS and practice selectors, colors, and text styling.

## 🎯 Objectives
- Understand inline, internal, and external CSS.
- Learn element, class, and ID selectors.
- Apply text colors and background colors.
- Style headings and paragraphs.

## 📝 Tasks Performed
1. Created `inline-internal.html`.
2. Used internal CSS to style h1 elements in navy.
3. Applied a yellow background to the highlight class.
4. Used inline CSS to change a paragraph's text color to red.
5. Created `style.css` with element, class, and ID selectors.
6. Styled h1 elements, note classes, title IDs, and paragraphs.
7. Created `linked.html` and linked the external stylesheet.
8. Opened the pages in a browser to verify the styling.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood the three common methods of applying CSS.
- Learned how CSS selectors target HTML elements.
- Practiced styling text and backgrounds.
- Learned how to connect an external stylesheet to an HTML page.

## ✅ Conclusion
Successfully applied inline, internal, and external CSS and practiced basic selectors and text styling.
