Task 4.1: Create layout.html

Aim: Create three div blocks with the classes header, main and footer, each containing text.

Software / Tools Required: HTML editor and web browser.

Theory: The div element is a generic container used to group content. A class attribute identifies elements for styling or scripting.

Algorithm / Procedure:
1. Create layout.html.
2. Add header, main and footer divs.
3. Assign each the required class.
4. Open the page in a browser.

Program / Queries / Commands:

layout.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Layout</title>
</head>
<body>
  <div class="header">Header Section</div>
  <div class="main">Main Content</div>
  <div class="footer">Footer Section</div>
</body>
</html>

Input: Text for header, main and footer.

Output: Three blocks appear in header, main and footer order.
 
Result: The task was performed and the expected output can be verified after running the supplied code/commands.
