Task 4.2: Create attributes.html

Aim: Give a div the id profile and put a paragraph inside it with data-topic="hobbies".

Software / Tools Required: HTML editor and web browser.

Theory: An id identifies a unique element in a document. Custom data-* attributes store extra information and are not displayed as visible text by default.

Algorithm / Procedure:
1. Create attributes.html.
2. Add a div with id profile.
3. Add a paragraph with data-topic="hobbies".
4. Open the page and inspect the element if needed.

Program / Queries / Commands:

attributes.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Profile</title>
</head>
<body>
  <div id="profile">
    <p data-topic="hobbies">My hobbies are reading and coding.</p>
  </div>
</body>
</html>

Input: Paragraph text describing hobbies.

Output: Paragraph text appears; the data-topic attribute is not visible on the page.


Result: The task was performed and the expected output can be verified after running the supplied code/commands.
