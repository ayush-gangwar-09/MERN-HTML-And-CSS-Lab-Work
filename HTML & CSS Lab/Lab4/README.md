# Lab 4: Divs, Attributes and a Small Fix

## 📌 Aim
To organize webpage content using div elements, understand HTML attributes, and correct errors in an HTML document.

## 🎯 Objectives
- Understand the purpose of the `<div>` element.
- Use class and id attributes.
- Work with custom data attributes.
- Identify and fix HTML syntax errors.

## 📝 Tasks Performed
1. Created `layout.html` with header, main, and footer div blocks.
2. Assigned appropriate class names to the div elements.
3. Created `attributes.html` with a div having the id `profile`.
4. Added a paragraph with the `data-topic="hobbies"` attribute.
5. Examined an HTML document containing incorrect heading and paragraph tags.
6. Corrected the missing closing tags.
7. Saved the corrected document as `attendance-fixed.html`.
8. Opened the pages in a browser to verify the output.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned how to group webpage content using div elements.
- Understood the difference between class and id attributes.
- Learned the purpose of custom data attributes.
- Improved the ability to identify and correct HTML errors.

## ✅ Conclusion
Successfully practiced content grouping, HTML attributes, and basic error correction.
