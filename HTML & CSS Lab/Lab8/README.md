# Lab 8: Sign-Up Forms and Choices

## 📌 Aim
To create HTML forms with different input fields, selection controls, and basic browser validation.

## 🎯 Objectives
- Understand the HTML form element.
- Create text, email, and password fields.
- Connect labels with form controls.
- Use radio buttons and dropdown lists.
- Apply required-field validation.

## 📝 Tasks Performed
1. Created `signup.html` with a registration form.
2. Added full name, email, and password fields.
3. Connected labels with inputs using the `for` and `id` attributes.
4. Set the form method to POST and its action to `thanks.html`.
5. Created `choices.html` with gender radio buttons.
6. Added a course dropdown containing BCA and B.Tech.
7. Created `signup-required.html` with required name and email fields.
8. Added a placeholder to the name field.
9. Included a Submit button and tested browser validation.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned how to create HTML forms.
- Understood different input types.
- Practiced labels, radio buttons, and dropdowns.
- Learned basic browser-based form validation.

## ✅ Conclusion
Successfully created registration forms with different input controls and required-field validation.
