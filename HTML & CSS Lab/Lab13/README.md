# Lab 13: Flexbox Layouts

## 📌 Aim
To design flexible webpage layouts using CSS Flexbox properties.

## 🎯 Objectives
- Understand the Flexbox layout model.
- Create horizontal navigation bars.
- Align and center multiple cards.
- Implement wrapping layouts.

## 📝 Tasks Performed
1. Created `nav-flex.html` with a navigation bar containing Home, About, Events, and Contact links.
2. Applied `display: flex` to arrange the links horizontally.
3. Styled the navigation bar with a dark background and white text.
4. Created `centred-cards.html` with Starter, Standard, and Premium cards.
5. Added prices to each card.
6. Used `justify-content` and `align-items` to align the cards.
7. Created `wrapping-cards.html` with stationery product cards.
8. Added Notebook, Pen, Bag, and Book cards with prices.
9. Applied `flex-wrap` to allow cards to move to new rows.
10. Tested the layout at different browser widths.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Flexbox
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned how to arrange elements using Flexbox.
- Understood horizontal and vertical alignment.
- Practiced creating navigation bars and card layouts.
- Learned how flex-wrap supports flexible layouts.

## ✅ Conclusion
Successfully created navigation bars, centered card layouts, and wrapping product cards using CSS Flexbox.
