# Lab 11: Units and CSS Variables

## 📌 Aim
To understand CSS measurement units and use CSS variables for reusable styling.

## 🎯 Objectives
- Learn pixel, percentage, and rem units.
- Understand the use of CSS variables.
- Define variables inside the :root selector.
- Apply variables using the var() function.

## 📝 Tasks Performed
1. Created `units.html` with boxes of different widths.
2. Set one box to 200px wide and another to 50% width.
3. Applied a height of 40px to both boxes.
4. Set paragraph text to 1.5rem.
5. Created `variables.html` with heading and paragraph elements.
6. Defined main color, accent color, and page padding variables.
7. Applied variables to body styling and heading colors.
8. Created `tokens.css` with reusable color, heading-size, and spacing variables.
9. Verified the output in a browser.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood different CSS measurement units.
- Learned how to define and reuse CSS variables.
- Practiced consistent color and spacing management.
- Understood how reusable design values simplify stylesheet maintenance.

## ✅ Conclusion
Successfully practiced CSS units and variables to create consistent and maintainable webpage styles.
