# Lab 15: Responsive Pages with Media Queries

## 📌 Aim
To create responsive webpages that adapt to different screen sizes using CSS media queries and responsive image techniques.

## 🎯 Objectives
- Understand responsive web design.
- Create mobile-first layouts.
- Use media queries to modify layouts.
- Make images scale according to available space.
- Adjust typography for different screen widths.

## 📝 Tasks Performed
1. Created `mobile-first.html` with a viewport meta tag.
2. Added two cards inside a container.
3. Designed the initial layout for mobile screens.
4. Added a media query for screens 600px wide and above.
5. Changed the card layout to display cards side by side on wider screens.
6. Created `responsive-image.html` with an image from the images folder.
7. Applied `max-width: 100%` and `height: auto` to make the image responsive.
8. Created `responsive-text.html` with a heading and paragraph.
9. Set the body font size to 1rem and the heading size to 1.5rem.
10. Added a media query to increase the heading size to 2.5rem on wider screens.
11. Tested the webpages at different browser widths.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Media Queries
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood the principles of responsive web design.
- Learned how to implement mobile-first layouts.
- Practiced changing layouts with media queries.
- Learned how to make images responsive.
- Understood responsive typography using rem units.

## ✅ Conclusion
Successfully created responsive webpages using media queries, flexible images, and adaptive text sizes for different screen widths.
