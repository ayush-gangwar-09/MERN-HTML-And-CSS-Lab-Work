# Lab 9: Tables with Headers and Footers

## 📌 Aim
To create structured HTML tables using captions, headers, body rows, footers, and accessibility attributes.

## 🎯 Objectives
- Understand HTML table structure.
- Use table headings and data cells.
- Organize table content using semantic elements.
- Display student marks and calculate averages.
- Improve accessibility using scope attributes.

## 📝 Tasks Performed
1. Created `marks.html` with the caption "Marks of Class A".
2. Added columns for Name, Maths, and Science.
3. Inserted student records for Asha, Rohan, and Neha.
4. Used `<thead>` for the header row and `<tbody>` for student records.
5. Created `marks-average.html` with Asha and Rohan's marks.
6. Calculated the average Maths and Science marks of the two students.
7. Added a footer row using `<tfoot>`.
8. Created `marks-accessible.html` with scope attributes.
9. Tested the tables in a browser.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned how to structure HTML tables.
- Understood table captions, headers, bodies, and footers.
- Practiced displaying and calculating student marks.
- Learned how scope attributes improve table accessibility.

## ✅ Conclusion
Successfully created HTML tables with structured sections, calculated averages, and accessibility attributes.
