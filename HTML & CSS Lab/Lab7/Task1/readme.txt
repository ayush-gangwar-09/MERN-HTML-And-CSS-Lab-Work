Task 7.1: Create about-me.html structure

Aim: Create a header with your name in h1 and a nav with About and Contact links; include empty main and footer.

Software / Tools Required: HTML editor and web browser.

Theory: Semantic elements such as header, nav, main and footer describe the role of page regions.

Algorithm / Procedure:
1. Create about-me.html.
2. Add header, h1 and nav.
3. Link About to #about and Contact to #contact.
4. Add empty main and footer elements.

Program / Queries / Commands:

about-me.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>About Me</title>
</head>
<body>
  <header>
    <h1>Ayush Kumar</h1>
    <nav>
      <a href="#about">About</a>
      <a href="#contact">Contact</a>
    </nav>
  </header>
  <main></main>
  <footer></footer>
</body>
</html>

Input: Use your own name.

Expected Output: Your name and two navigation links appear at the top; main and footer are empty.

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
