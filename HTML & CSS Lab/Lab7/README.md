# Lab 7: About Me Page

## 📌 Aim
To develop a personal webpage using semantic HTML elements and internal navigation links.

## 🎯 Objectives
- Understand semantic HTML elements.
- Create a personal About Me webpage.
- Implement navigation links.
- Add an email contact link.

## 📝 Tasks Performed
1. Created `about-me.html`.
2. Added a header containing a personal heading.
3. Created a navigation bar using the `<nav>` element.
4. Added About and Contact links.
5. Created a main section containing an About Me heading and paragraph.
6. Used the `<section>` element with the id `about`.
7. Added a footer with the id `contact`.
8. Created an email link using the `mailto:` protocol.
9. Tested the navigation links in a browser.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned the purpose of semantic HTML elements.
- Understood webpage section organization.
- Practiced internal navigation using element IDs.
- Learned how to create clickable email links.

## ✅ Conclusion
Successfully developed a personal webpage using semantic elements, navigation links, and an email contact link.
