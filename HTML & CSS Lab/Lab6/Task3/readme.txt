Task 6.3: Create faq.html

Aim: Create a description list with two questions as dt elements and answers as dd elements.

Software / Tools Required: HTML editor and web browser.

Theory: A description list uses dl as its container, dt for a term or question, and dd for its description or answer.

Algorithm / Procedure:
31.	1. Create faq.html.
32.	2. Add a dl element.
33.	3. Add each question in dt and its answer in dd.
34.	4. Open the page in a browser.

Program / Queries / Commands:

faq.html

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Library FAQ</title>
</head>
<body>
  <h1>Library FAQ</h1>
  <dl>
    <dt>How many books can I borrow?</dt>
    <dd>You can borrow up to four books at a time.</dd>
    <dt>Is the library open on Sunday?</dt>
    <dd>The library is closed on Sunday.</dd>
  </dl>
</body>
</html>

Input: Questions about borrowing books and Sunday library hours.

Output: Each question is followed by its answer.


Result: The task was performed and the expected output can be verified after running the supplied code/commands.
