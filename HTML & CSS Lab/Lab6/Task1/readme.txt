Task 6.1: Create shopping-list.html

Aim: Create a Shopping List heading and an unordered list containing Notebook, Pen and Bag.

Software / Tools Required: HTML editor and web browser.

Theory: An unordered list uses ul and list items use li. Browsers typically display bullet markers for unordered lists.

Algorithm / Procedure:
1. Create shopping-list.html.
2. Add the heading.
3. Add a ul with three li elements.
4. Open the page in a browser.

Program / Queries / Commands:

shopping-list.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Shopping List</title>
</head>
<body>
  <h1>Shopping List</h1>
  <ul>
    <li>Notebook</li>
    <li>Pen</li>
    <li>Bag</li>
  </ul>
</body>
</html>

Input: Notebook, Pen, Bag.

Output: Three bullet points appear.

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
