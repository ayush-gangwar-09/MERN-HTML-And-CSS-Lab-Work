Create a folder named html-lab and start a Git repository in it with git init. 
Set your own name and email for this repository only (git config --local). 
Then show them with git config user.name and git config user.email.

Each git config command prints the value you set.

Procedure:
1. Create and open the html-lab folder.
2. Run git init.
3. Set user.name and user.email with --local.
4. Display both values.

output:
