# Lab 1: Starting a Git Repository

## 📌 Aim
To create a local Git repository, configure Git user details, and understand basic version control operations.

## 🎯 Objectives
- Understand the concept of a Git repository.
- Initialize a repository using Git.
- Configure username and email locally.
- Track changes and save them using commits.
- View commit history.

## 📝 Tasks Performed
1. Created a folder named `html-lab`.
2. Initialized a Git repository using `git init`.
3. Configured the local Git username and email.
4. Created an `index.html` file with an HTML heading.
5. Checked the repository status using `git status`.
6. Added files using `git add` and committed changes using `git commit`.
7. Added another heading and created a second commit.
8. Viewed commit history using `git log --oneline`.

## 🛠️ Technologies Used
- Git
- HTML5
- Command Line / Terminal

## 📚 Learning Outcomes
- Learned how to initialize a Git repository.
- Understood staging and committing changes.
- Learned to configure local Git settings.
- Understood how Git tracks project history.

## ✅ Conclusion
Successfully created a local Git repository and practiced basic Git commands for tracking and managing project changes.
