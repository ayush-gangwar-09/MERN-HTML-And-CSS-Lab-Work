Task 5.3: Create portfolio-image.html

Aim: Create a page with a heading and a picture from the images folder, width and height 200, with descriptive alt text.

Software / Tools Required: HTML editor, browser and instructor-provided image.

Theory: The img element embeds an image. The alt attribute provides a text alternative, while width and height specify displayed dimensions.

Algorithm / Procedure:
1. Create portfolio-image.html.
2. Put the instructor-provided image in an images folder.
3. Use the correct relative image path.
4. Set width and height to 200 and provide alt text.

Program / Queries / Commands:

portfolio-image.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Portfolio Image</title>
</head>
<body>
  <h1>My Portfolio Image</h1>
  <img src="images/your-image.jpg" width="200" height="200" alt="A descriptive view of my project">
</body>
</html>


Input: Image file placed in images folder.

Expected Output: A 200 by 200 image appears below the heading; alt text appears if the image is unavailable.

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
