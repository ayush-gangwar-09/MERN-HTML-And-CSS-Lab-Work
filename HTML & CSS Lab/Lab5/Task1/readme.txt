Task 5.1: Create home.html

Aim: Create home.html with a Welcome to My Site heading and a paragraph linking to portfolio.html.

Software / Tools Required: HTML editor and web browser.

Theory: The anchor element creates hyperlinks. Its href attribute specifies the destination.

Algorithm / Procedure:
1. Create home.html.
2. Add the heading and paragraph.
3. Add an anchor with href="portfolio.html" and link text portfolio.
4. Keep portfolio.html in the same folder.

Program / Queries / Commands:

home.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Home</title>
</head>
<body>
  <h1>Welcome to My Site</h1>
  <p>Visit my <a href="portfolio.html">portfolio</a>.</p>
</body>
</html>

Input: Link text: portfolio.

Expected Output: Clicking portfolio opens portfolio.html when that file is present.

Result: The task was performed and the expected output can be verified after running the supplied code/commands.
