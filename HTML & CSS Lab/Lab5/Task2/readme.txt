Task 5.2: Create portfolio.html

Aim: Create portfolio.html with a heading and a link back to home.html.

Software / Tools Required: HTML editor and web browser.

Theory: Hyperlinks can connect pages in the same folder by using relative file paths.

Algorithm / Procedure:

1. Create portfolio.html.
2. Add a heading and some portfolio text.
3. Add a link to home.html.
4. Test navigation in the browser.

Program / Queries / Commands:

portfolio.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Portfolio</title>
</head>
<body>
  <h1>My Portfolio</h1>
  <p>Here are some of my projects.</p>
  <a href="home.html">Back to Home</a>
</body>
</html>

Input: Link text: Back to Home.

Expected Output: The link returns to the home page.

Viva-Voce Questions:
•	1. What is a relative URL?
•	2. Can an anchor link to another local HTML file?
•	3. What happens if the target file path is incorrect?
