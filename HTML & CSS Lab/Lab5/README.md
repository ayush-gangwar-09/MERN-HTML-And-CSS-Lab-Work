# Lab 5: Links and Images

## 📌 Aim
To create hyperlinks between webpages and insert images using HTML.

## 🎯 Objectives
- Understand hyperlink creation.
- Learn how to connect multiple HTML pages.
- Insert images using the img element.
- Use alternative text for images.

## 📝 Tasks Performed
1. Created `home.html` with the heading "Welcome to My Site".
2. Added a hyperlink to `portfolio.html`.
3. Created `portfolio.html` with a heading and a link back to the home page.
4. Created `portfolio-image.html` with a heading and an image.
5. Used the `<img>` element to display the image.
6. Set the image width and height to 200 pixels.
7. Added descriptive alternative text using the `alt` attribute.
8. Verified the links and images in a browser.

## 🛠️ Technologies Used
- HTML5
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Learned how to create internal links between webpages.
- Understood the use of the anchor element.
- Learned how to display images.
- Understood the importance of alternative text.

## ✅ Conclusion
Successfully created linked webpages and inserted images with appropriate dimensions and alternative text.
