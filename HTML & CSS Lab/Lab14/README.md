# Lab 14: CSS Grid Layouts

## 📌 Aim
To create structured webpage layouts using CSS Grid and responsive grid techniques.

## 🎯 Objectives
- Understand the CSS Grid layout model.
- Create grids with equal columns.
- Design responsive galleries.
- Use named grid areas to organize page sections.

## 📝 Tasks Performed
1. Created `grid-first.html` with six numbered boxes.
2. Used three equal columns with fractional units.
3. Applied a gap of 12px between grid items.
4. Created `gallery.html` with six photo placeholders.
5. Used `repeat(auto-fill, minmax(150px, 1fr))` for responsive columns.
6. Applied a gap of 10px between gallery items.
7. Created `dashboard-areas.html` with a two-column grid.
8. Used columns of 200px and 1fr.
9. Defined named areas for the header, sidebar, main content, and footer.
10. Tested the layouts in a browser.

## 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Grid
- Visual Studio Code
- Web Browser

## 📚 Learning Outcomes
- Understood rows, columns, and gaps in CSS Grid.
- Learned how to create equal-width grid columns.
- Practiced responsive gallery layouts.
- Learned how to arrange page sections using named grid areas.

## ✅ Conclusion
Successfully created grid layouts, a responsive gallery, and a dashboard layout using CSS Grid.
