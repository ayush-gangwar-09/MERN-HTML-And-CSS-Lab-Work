# HTML & CSS Development Lab (BCS554)

## 📌 About This Repository

This repository contains 15 lab assignments for the HTML & CSS Development Lab (BCS554) as part of the B.Tech Computer Science and Engineering curriculum at Invertis University, Bareilly.

The purpose of this repository is to practice HTML, CSS, Git, and GitHub through practical assignments. It covers basic HTML elements, forms, tables, CSS styling, Flexbox, Grid layouts, and responsive web design.

Each lab folder contains three tasks and its own README.md file describing the respective assignment.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code
- Web Browser

## 📚 Lab Assignments

### Lab 1: Starting a Git Repository
- Initialize a Git repository.
- Configure Git username and email.
- Create files and save changes using commits.

### Lab 2: Pushing and Cloning a Repository
- Create a remote repository.
- Push commits to a remote repository.
- Clone a repository and check commit history.

### Lab 3: Your First HTML Page
- Create a basic HTML document.
- Use headings and paragraphs.
- Apply text formatting.

### Lab 4: Divs, Attributes and a Small Fix
- Use div elements.
- Work with class, id, and data attributes.
- Fix errors in HTML code.

### Lab 5: Links and Images
- Create links between HTML pages.
- Insert images.
- Use the alt attribute.

### Lab 6: Types of HTML Lists
- Create unordered lists.
- Create ordered and nested lists.
- Create description lists.

### Lab 7: About Me Page
- Create a personal webpage.
- Use semantic HTML elements.
- Add navigation and email links.

### Lab 8: Sign-Up Forms and Choices
- Create registration forms.
- Use text, email, and password fields.
- Add radio buttons, dropdowns, and required fields.

### Lab 9: Tables with Headers and Footers
- Create HTML tables.
- Use thead, tbody, and tfoot.
- Display student marks and calculate averages.
- Improve accessibility using scope attributes.

### Lab 10: CSS Fundamentals
- Apply inline CSS.
- Use internal CSS.
- Link external CSS stylesheets.
- Work with CSS selectors and text styling.

### Lab 11: Units and CSS Variables
- Use px, percentage, and rem units.
- Define CSS variables.
- Apply variables using the var() function.

### Lab 12: Box Model, Cards and Scrolling
- Understand the CSS Box Model.
- Compare content-box and border-box.
- Design cards using CSS.
- Implement scrolling using overflow.

### Lab 13: Flexbox Layouts
- Create navigation bars.
- Align and center cards.
- Use Flexbox properties.
- Implement responsive card wrapping.

### Lab 14: CSS Grid Layouts
- Create grid layouts.
- Design a responsive photo gallery.
- Use grid-template-columns and gap.
- Create dashboard layouts using grid areas.

### Lab 15: Responsive Pages with Media Queries
- Create mobile-first layouts.
- Use CSS media queries.
- Make images responsive.
- Adjust text sizes for different screen widths.

## 🎯 Learning Outcomes

- Understand HTML page structure.
- Apply CSS styling to webpages.
- Create forms, tables, lists, links, and images.
- Design layouts using Flexbox and CSS Grid.
- Develop responsive webpages.
- Understand basic Git and GitHub workflows.
- Organize web development projects effectively.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the required Lab folder.
4. Open the desired Task folder.
5. Open the HTML file in a web browser.
6. Check the output and modify the code as needed.
